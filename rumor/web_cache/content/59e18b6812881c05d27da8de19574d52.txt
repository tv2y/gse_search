### Solution

The statement is **True**.

PowerPoint 2016 includes seven different views that help users create and present slides. These views are:

1.   **Normal View** – Default editing view.
2.   **Slide Sorter View** – Displays thumbnails of all slides for easy organization.
3.   **Reading View** – A way to preview the presentation in a window.
4.   **Slide Show View** – Full screen presentation mode.
5.   **Outline View** – Shows the presentation as an outline.
6.   **Notes Page View** – Allows you to add speaker notes.
7.   **Master Views** – Includes Slide Master, Handout Master, and Notes Master; these are used for formatting.

Therefore, the statement that there are 7 views available in PowerPoint 2016 is true.
