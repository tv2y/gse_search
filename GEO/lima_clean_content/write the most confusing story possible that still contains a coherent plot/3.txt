Here are the key takeaways from the discussion with David D. Levine about handling complicated plots:

1. **Understanding Plot Structure**:  
   - A story is a collection of incidents, characters, and settings.  
   - Plot is founded on cause-and-effect relationships between these incidents.  

2. **List All Plot Elements**:  
   - Start by clearly identifying all plot elements, either through outlining (plotters) or discovery writing (pantsers).  

3. **Visualizing the Plot**:  
   - Imagine the plot as a four-dimensional array of incidents, each like a bead in space-time.  
   - Techniques include using Post-it notes or Scrivener to rearrange incidents for narrative flow.  

4. **Crafting Cause-and-Effect Relationships**:  
   - Every incident should influence subsequent events, creating a web of interconnected actions and consequences.  

5. **Choosing Narrative Order**:  
   - Authors can manipulate incident order (e.g., flashbacks, nonlinear storytelling) to create desired effects on readers.  

6. **Managing Multiple Narrators**:  
   - Balance parallel plotlines by alternating scenes, using cliffhangers, or intertwining character arcs.  

7. **Balancing Simultaneous Events**:  
   - Depict simultaneous events by cutting between scenes, controlling pacing and tension for seamless transitions.  

For pantsers, the process involves drafting first and then reorganizing; for plotters, it’s about structuring incidents upfront. Tools like Scrivener help rearrange scenes for coherence.
