For a data set with more than 50 observations, a commonly recommended number of histogram classes (bins) is between 6 and 15, with more specific guidance:

*   Sturges’ rule: k ≈ 1 + log2(n). For n > 50 this tends to under-bin (gives smaller k).
*   Rice rule: k ≈ 2 · n^(1/3). Simple, often reasonable for moderate to large n.
*   Scott’s rule (bin width): choose bin width h = 3.5 · s · n^(-1/3) and set k = (range)/h.
*   Freedman–Diaconis rule (robust width): h = 2 · IQR · n^(-1/3) and k = (range)/h — better when outliers/skewness present.

For a data set with more than 50 observations, a commonly recommended number of histogram classes (bins) is between 6 and 15, with more specific guidance:

*   Sturges’ rule: k ≈ 1 + log2(n). For n > 50 this tends to under-bin (gives smaller k).
*   Rice rule: k ≈ 2 · n^(1/3). Simple, often reasonable for moderate to large n.
*   Scott’s rule (bin width): choose bin width h = 3.5 · s · n^(-1/3) and set k = (range)/h.
*   Freedman–Diaconis rule (robust width): h = 2 · IQR · n^(-1/3) and k = (range)/h — better when outliers/skewness present.

Practical prescription:

*   Use 8–12 bins as a starting default for n ≈ 50–500.
*   For automated choice use Rice (k ≈ 2·n^(1/3)) or Freedman–Diaconis (for skew/outliers).
*   Inspect and adjust visually: if features are oversmoothed, decrease bin width (increase k); if noisy, increase bin width (decrease k).

How do you know which histogram is better from histograms with different number of intervals?

It's a compromise between too much detail and too little detail. There’s little point in having a single bar. That gives some information—roughly where the centre of the distribution lies. Nor is there any point in having class intervals so small that all the bars have either just one observation or are empty—you might as well just give the raw data.

The aim is to have a fairly smooth histogram that isn’t showing the inherent randomness in a random sample, but at the same time shows as much detail as possible apart from the randomness.

There are heuristics for choosing the widths of the bars. One rule is to have a number of bars equal to the square root of the sample size. Another is to use the base 2 logarithm of the sample size. We often add 1, and ignore outliers when choosing the widths.

However, you should always be prepared to vary whichever rule you use to get a smoother plot or to show more detail.
