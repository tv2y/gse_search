> ABSTRACT

Elevator is a convenient building transportation for people to travel, and more and more elevators are being 

registered and put into use, and the  ACCOMPANYING  problems of elevator failure and maintenance are 

becoming more and more prominent. In this study, the Kalman filter algorithm is used to optimize the 

feature extraction performance and prediction accuracy of the deformable convolutional TimesNet model 

for  elevator operation time series data, and the improved TimesNet model is fused with the DLinear model 

to construct the TimesNet -DLinear model for predicting elevator operation accidents. Finally, the 

TimesNet -DLinear model is used as the main analysis modu le to design the elevator operation accident 

prediction system. After testing, it is found that the TimesNet -DLinear model can maintain a low error in 

the prediction of elevator operation data, with an average absolute error of  0.167 , and the prediction 

ac curacy is better than other prediction models. It is also found that the elevator operation accident 

prediction system is able to predict the accidents in the elevator operation in a certain district and make a 

warning according to the current error thresh old situation. The elevator operation accident prediction 

system proposed in this study is able to realize real -time monitoring and early warning of elevator failures, 

providing an effective solution for real -time decision -making and scheduling of elevator  maintenance. 

Keywords:  TimesNet , Dlinear , feature extraction , Kalman filter , elevator accident prediction

2.1.3. Model improvement based on Kalman filter algorithm . Kalman filtering algorithm is a recursive 

filtering algorithm [ 28 ], which estimates the state of the signal by using observed data and predictive 

models. In the Kalman filtering algorithm, the noise and interferenc e in the measurement is removed by 

estimating the signal state and modeling the measurement error and system noise to get a more accurate 

signal estimation. 

The Kalman filtering algorithm is based on Bayesian theory, which regards the signal state as a sto chastic 

process, and predicts the future state by modeling and predicting it. At the same time, the Kalman filtering 

algorithm also utilizes the measurement error of the sensor data and the characteristics of the system 

noise to correct the prediction resu lts and obtain more accurate signal estimation results. 

The specific implementation of the Kalman filtering algorithm in a one -dimensional time series includes 

the following steps: 

1) Establish a state space model: model the signal as a random variable tha t changes over time. 

2) Predict the state: according to the current state space model, predict the value of the next state. 

3) Calculate Kalman gain: based on the error between the predicted state and the observed value, 

calculate the Kalman gain, which is  used to correct the predicted value. 

4) Update the state: according to the Kalman gain, the predicted state is corrected to get a more accurate 

state estimate. 

5) Update state covariance: according to the observed value and Kalman gain, update the state c ovariance 

to reflect the accuracy of state estimation. Through the above steps, the Kalman filtering algorithm can 

remove the noise and interference in the measurements, so as to obtain a more accurate one -dimensional 

time series. 

Therefore, in this paper, the improvement of the convolvable TimesNet model is realized by introducing 

the Kalman filtering algorithm to deal with the individual outliers generated in the elevator operation data.

2.2. DLinear model construction 

DLinear [ 30 ] is a new type of high -accuracy time series prediction model.The simple structure of DLinear ,

which consists of only one decomposition scheme and two linear connectivity networks, reduces the 

computational memory and computational time consumed during model training.DLinear not only has a 

very simple model structure, but also has significantly be tter prediction accuracy than the more complex 

LSTM model. In the process of elevator operation fault prediction, DLinear firstly decomposes the original 

time series inputs by a moving average kernel to obtain the trend and seasonal components of the power 

load data, and then assigns weights to the decomposed components by using two single -layer time linear 

layers according to the basic formula. Finally, the outputs of the linear layers are combined to obtain the 

prediction results. 

The two temporal linear  layers decompose the seasonal and trend components of the input data for 

separate prediction. DLinear can significantly improve the prediction performance of the network by 

processing the trend and seasonality of the time series data, especially for the el evator operation data with

## 5. Conclusion 

In this study, the TimesNet -DLinear model is established by integrating the DLinear  model with the 

TimesNet model improved based on the Kalman filter algorithm to realize the prediction of elevator 

operation accidents, and the elevator operation accident prediction system is designed and obtained. The 

analysis of the prediction accuracy  of the model shows that the average absolute error ( 0.167 ), the mean 

square error ( 0.3496 ) and the average absolute percentage error ( 2.94 %) of the TimesNet -DLinear model 

in predicting the various parameters in the elevator operation process are lower than  those of the 

comparison model, and it also performs optimally on the evaluation index 2

R (97 .46 %). This indicates 

that the model is more accurate in predicting different parameters such as current and acceleration during 

elevator  operation. An application analysis of the elevator operation data in a community reveals that the 

elevator operation accident prediction system proposed in this paper is able to successfully detect elevator 

operation accidents and early anomalies before ac cidents occur. 

The research in this paper contributes to the research in the field of elevator safety risk monitoring and 

early warning, and the designed elevator operation accident prediction system is able to effectively predict 

elevator failures and  make early warnings. Further research can be carried out in the future to make the
