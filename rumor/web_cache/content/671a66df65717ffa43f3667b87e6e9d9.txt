More actions

*   add `--referer "URL"` to your yt-dlp command, replacing `URL` with the actual URL of the webpage that you are getting the m3u8 link from
*   add `--cookies-from-browser chrome` to your yt-dlp command, or replace `chrome` with the name of the browser that you are logged into the site with

If that doesn't work, it's possible that there are other HTTP headers required by the site. You could look in your browser's dev tools and see what other headers your browser is sending with the request for the m3u8. You can use the `--add-header` option to pass these to yt-dlp, e.g. `--add-header "Accept:*/*"`
